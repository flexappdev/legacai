# ProdGame

Keeps goals and outcomes honest, and turns lessons into durable legacy knowledge.

## Steps

1. **Read** `vault/live/goals.md`, `vault/live/projects/`, and DJAI entries since the last review (`vault/input/djai/`). Create `goals.md` if missing, asking for the top 3 goals per active scope.
2. **Score** each goal: progress since last review, streaks for routines, blocked items. Evidence only from linked entries.
3. **Write the review** to `vault/input/prodgame/<period>-<date>.md`: Wins · Misses · Lessons · Next 3 moves · Goals to retire.
4. **Lessons:** each lesson gets scope, horizon and a source link, so the sweep can promote repeated lessons to `wiki/<scope>/lessons/`.
5. **Year review only:** propose one letter-to-the-future line per scope for the vault's release plans.

## Rules

- Never mark progress without a linked entry.
- Retired goals stay in history with the reason.
