# Vault

INPUT → LIVE → WIKI, run by the `legacai-sweep` skill.

- `input/`: raw, append-only. Private source material (real names, raw chats) is **not** kept here because this repo is public; it lives in the private project folder and is referenced as `private:<path>`.
- `live/`: current state with pseudonymous ids, `meta/` sidecars, `people/`, `now.md`, `review.md`.
- `wiki/`: durable, cited pages. Promotion needs consent `granted` for every living person.
